A **symbol table** is a fundamental data structure used by a compiler to store and manage information about identifiers (such as variables, functions, classes, and constants) encountered in a program. Each entry in the symbol table typically contains details like the identifier’s name, data type, scope (local or global), memory location, and sometimes its value or additional attributes. During compilation, the symbol table is continuously updated and consulted across multiple phases—lexical analysis adds new symbols, syntax and semantic analysis use it to validate declarations and type correctness, and later stages rely on it for memory allocation and code generation. It plays a crucial role in error detection, such as identifying undeclared variables, type mismatches, or scope violations. Conceptually, a symbol table acts as the compiler’s “memory” of the program, allowing it to efficiently track and organize all identifiers so that the code can be correctly interpreted, validated, and translated into machine instructions.
